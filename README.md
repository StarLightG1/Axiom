
# Axiom

**Axiom Advanced Mathematics** is a Flutter-based advanced mathematics calculator and graphing toolkit designed for fast, local-first mathematical exploration.

## Features

- Scientific calculator
- Advanced mathematical expressions
- Trigonometric, inverse trigonometric, and hyperbolic functions
- Mathematical constants such as π, e, and φ
- DEG / RAD / GRAD angle modes
- Memory functions
- Calculation history
- Interactive function graphing
- Multiple functions on the same graph
- Zoom and pan controls
- Coordinate tracing
- Root detection
- Extrema detection
- Derivative and integral analysis
- Statistics toolkit
- Unit conversion tools
- Configurable application settings
- Local data persistence

## Technology

- Flutter
- Dart
- Custom mathematical expression engine
- Custom graphing and mathematical analysis components
- Local-first architecture

## Platform

The current release is provided as an Android APK.

## Release

Download the latest Axiom APK from the **Releases** section of this repository.

## Project Status

This is the initial submission release of Axiom.  
The project will continue to receive improvements, additional mathematical tools, UI refinements, and performance enhancements in future versions.
